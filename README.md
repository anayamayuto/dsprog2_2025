# 天気予報アプリ (Weather App)

このプロジェクトは、Pythonを使用した天気予報データ管理・表示アプリのプロジェクトです。

## プロジェクト概要
天気の情報を取得し、データベースに保存・管理するためのプログラム群が含まれています。

## 主要なファイル・ディレクトリ構成
- `weather/` : 天気情報に関するメインの処理やモジュールが格納されています。
- `weatherdb/` : 天気予報のデータベース操作（CRUDなど）に関するコードが格納されています。
- `weather.db` : 天気情報が保存されるSQLiteデータベースファイルです。
- `.venv/` : Pythonの仮想環境ディレクトリです。
- `*.ipynb` : 各種Pythonの演習や実験用のJupyter Notebookです。

## 環境構築・実行方法
本プロジェクトはPythonを使用しています。開発を始める際は、仮想環境を有効化してください。

```bash
# 仮想環境の有効化 (Mac/Linuxの場合)
source .venv/bin/activate
```

プログラムの実行方法は、対象のスクリプトやJupyter Notebookを参照してください。
